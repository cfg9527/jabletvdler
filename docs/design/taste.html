Textual TUI · Age gate · Late night

A terminal dressed in blush.

JableTV Downloader is not a dark-mode utility with a pink sticker. It is a late-night machine whose identity is pink, whose work color is periwinkle, and whose windows breathe.

Designer taste

The taste is unapologetic pink on blue-black cinema. Surfaces sit at #161a26 — not generic charcoal, not VS Code gray — a navy so dark it reads as a room with the lights off. Against that room, the brand is not a 2px accent. It is the window itself: a heavy pink frame that inhales and exhales between #fe628e and hotpink.

The designer chose Textual over a desktop GUI so the app can live over SSH, then refused to let “terminal-native” mean austere. Figlet slant on the age gate. Bilingual legal copy in gold and amber. Hover states that flash hotpink and go bold — desire as a pointer event. A speed sparkline in accent. Footer keys in secondary pink.

This is camp with a straight face: ceremony at the door (18+), a quiet workbench in the middle, and CSS already written for confetti, checkmarks, and a farewell screen — ritual designed before it was wired. Adult, not crude. Fashionable, not ironic.

Pink is the brand. Periwinkle is the job. Hover is the blush. PinkyTheme · jabletv/themes.py

Chrome & type

Window

Everything lives inside #window-wrapper: 100% fill, heavy accent border, titled per screen — Age Gate, JableTV Downloader, Library, Dashboard. Inner panels use a muted stone border until focus, then they flush pink. The main column is 80 characters wide, centered. A TUI that still believes in 80 columns.

Type

Terminal default + figlet slant for the gate. Copy hierarchy is color, not size: primary #e0e0e0, secondary #b8babc, muted #8e9194. Metadata uses cyan for codes, yellow for names, italic for tags — Rich markup as typography, not decoration.

Layout personality

Structure is quiet. Color is loud. The download form is a vertical stack: URL, three equal actions, progress, sparkline, status, metadata, log. Library is search + table + detail. Dashboard is a 2×2 of panes. No chrome for chrome’s sake — then a single theatrical object (the breathing frame, the figlet) carries the fashion.

Language

English warning in gold bold. Japanese warning in amber. The product speaks two registers at once: legal clarity and late-night JP/EN adjacency. Buttons are plain speech: Yes, I am 18+ / No / Download / Back.

Motion: breathe, then blush

The outer border animates for 3 seconds toward #ff69b4, then 3 seconds back to #fe628e. That is the only ambient motion. Hover is the other half of the personality: secondary surfaces stay dim until the pointer arrives, then they become hotpink, white, and bold in one beat. Work stays periwinkle until you hover it — then it blushes too.

Hover any control. The theme does not fade toward pink — it snaps into it.

Screens as costume changes

Same room, different outfits. The frame never leaves. What changes is how much pink you are allowed to feel.

Taste rules

  1. Pink is identity, not a highlight. If you can remove the pink and the product still looks like “any TUI,” the design has failed. The heavy frame, the figlet, the hover blush, and the progress fill must remain pink.
  2. Periwinkle does the work. Primary actions (Download, Open URL, Yes) may start cool. They are allowed to blush on hover. Do not make every button pink at rest — that would flatten the desire curve.
  3. Navy is a room, not a theme preset. Keep #161a26 / #191d28. Do not drift into pure black or warm charcoal. The blue in the black is what makes the rose look expensive.
  4. Quiet structure, loud color. Centered 80-col stacks, muted stone borders, one theatrical object. Resist extra panels, shadows, and fake window chrome.
  5. Hover snaps. Ambient breathes. Border: 3s ease, two pinks. Pointer: instant hotpink + bold + white text. No other animation unless it reports speed (sparkline).
  6. Ceremony at the edges. Age-gate the session. Keep bilingual warnings. Leave room for a farewell. A downloader can still have a door and a goodbye.
  7. Terminal-native, dressed. Textual, SSH, figlet, Rich markup, footer keys. Never a CustomTkinter skin pretending to be an OS app.

Refuse / prefer

Refuse

Blue-accent “hacker” dark mode. Purple vaporwave soup. Light theme. Rounded consumer-app cards. Tiny pink dots on gray chrome. Skipping the age gate. Ironic Comic Sans energy.

Prefer

One rose family, one periwinkle family, one navy room. Heavy border. Slant figlet. Gold/amber legal type. Hotpink as a verb. 80 columns. Keys in secondary pink.

Why these architecture choices look like this

The design doc’s decisions are taste, encoded. Textual over CustomTkinter keeps the fashion inside a real terminal — the pink has to survive 16 colors, SSH latency, and a monospace grid, so it is painted in large strokes (heavy border, figlet, full-width bar), not in hairlines. httpx / threads / ffmpeg stay invisible; the UI only owes the user a blushing bar, a sparkline, and a centered status line. When the scrape resolves, metadata appears as a sudden inner panel — the workbench growing a card, not a new window.

The leftover CSS for #complete-screen, #variant-confetti, and #farewell-art is not dead weight. It is the designer’s intent: after the job, a beat of theatre; on quit, a goodbye in deeppink. Implement those screens in the same voice. Do not replace them with a toast.
